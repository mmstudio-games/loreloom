# Changelog

<!-- semifold:release version=0.1.0-alpha.0 -->
## v0.1.0-alpha.0

### Bug Fixes

- [`f1f66b3`](https://github.com/mmstudio-games/loreloom/commit/f1f66b327281bed04d5878471c62ce039bbf760d): Treat a directory Mod's root `.gitignore` as local authoring metadata instead of an unsupported package payload, without relaxing validation for other unknown or nested files.
- [`234db6d`](https://github.com/mmstudio-games/loreloom/commit/234db6d8318366ec014b51c48e3f7869f787e5db): Make generated NPC drafts minimal and recoverable: trusted agent profiles now come only from the locked generation policy, empty role collections may be omitted, knowledge and goal schemas match their Rust wire types, and invalid drafts report safe field categories. End the generation stage on the first accepted draft instead of spending another model call on discarded prose.
- [`8ba5678`](https://github.com/mmstudio-games/loreloom/commit/8ba567805973c726ea692ba8521772f94c1f02d8): Define NPC generation as a single-purpose tool stage that ends on the first accepted draft, keeps trusted agent bindings out of model input, accepts omitted empty collections, and reports only safe field-level draft validation categories.
- [`cdd11e8`](https://github.com/mmstudio-games/loreloom/commit/cdd11e89b4db2c81c9a190560362d710f30961c9): Remove the Manifest and Runtime response-language policy and its English system messages. Let root world and Mod Narrator/NPC prompts own fixed or player-following language behavior without a separate compatibility field.

### Chores

- [`83fc5a3`](https://github.com/mmstudio-games/loreloom/commit/83fc5a39b256acbb17800a13c653c3ee20ed6ad1): Freeze Scene as a persistent narrative container and Place as a connected location node. Document Narrator-owned runtime Scene/Place creation, bidirectional Place edges, generated provenance, delayed execution, and mandatory replanning before implementation.
- [`c3c2401`](https://github.com/mmstudio-games/loreloom/commit/c3c240182372934c11d77db687e47073a813e2d2): Freeze a read-only Mods overlay and safe startup package catalog. Keep the root World separate, distinguish enabled ModLock entries from valid installed-but-disabled directory packages, summarize unavailable candidates without exposing paths or content, and reserve Alt+M or F2 for viewing and scrolling without changing Runtime or persistent state.
- [`63c165d`](https://github.com/mmstudio-games/loreloom/commit/63c165d65579186031363e389c50c447616224b1): Validate atomic two-phase Content Registry loading and a unified preset/generated CharacterSpawnSpec and NpcFactory path with stable-reference resolution, full rollback, generated-origin recovery, and content-lock enforcement.
- [`c6777e6`](https://github.com/mmstudio-games/loreloom/commit/c6777e69e7cca48d70138c502cecfade0344b23e): Validate bounded directory Mod packages, deterministic dependency and Patch loading, exact ModLock recovery, typed parameters, revision-safe events, generic gameplay actions, and declarative rule budgets.
- [`2b4a40e`](https://github.com/mmstudio-games/loreloom/commit/2b4a40e196895715103289ee4f6e3c9391c5c568): Initialize the Loreloom Cargo workspace, crate boundaries, version policy, Semifold configuration, and implementation gates.

### New Features

- [`6fab674`](https://github.com/mmstudio-games/loreloom/commit/6fab67407304ef678269363bf30f4df1f7c41517): Hide Condition names from character and UI projections until the observing Actor owns a confirmed diagnosis KnownFact, while retaining intensity-filtered symptoms and loading the engine diagnosis Tag through the normal built-in Mod pipeline.
- [`62ba87c`](https://github.com/mmstudio-games/loreloom/commit/62ba87cb62fc453c18c39a426e6bfabffe17883f): Execute typed event options, capability-gated gameplay actions, save/session parameters, and deterministic declarative rule cascades through durable runtime tools.
- [`5754b85`](https://github.com/mmstudio-games/loreloom/commit/5754b850a1307a080e869ecf90a773d5bc6b8297): Persist bidirectional Place connections, expose adjacent destinations in Scene context, and require ordinary movement to follow those edges. Add Narrator-only delayed tools that atomically create generated inactive Scenes or connected Places, preserve generated provenance, and replan from the committed topology before transition or movement.
- [`1924090`](https://github.com/mmstudio-games/loreloom/commit/1924090337b8714351738ccc9b67c7f3a6074780): Let root worlds and enabled Mods declare ordered Narrator and NPC global context through the same `[prompts]` manifest table. Append Mod prompts deterministically by dependency topology without granting Tools or capabilities, include their source files in content locks, and keep undeclared prompt resources out of Agent requests.
- [`cae0e55`](https://github.com/mmstudio-games/loreloom/commit/cae0e55d87c831bfd41897ab319b3bd8bb6d9014): Project the root World, enabled ModLock entries, and safely inspected installed-but-disabled directory packages into each UI snapshot. Reuse activation integrity checks, keep invalid or unreadable installed candidates non-fatal and summarized, and exclude paths, hashes, and package content from the catalog view.
- [`08a96d0`](https://github.com/mmstudio-games/loreloom/commit/08a96d0a72a9a7208fa0f61ec9d12cef7f48f20a): Project validated per-Mod content summaries from compiled enabled packages and inspected installed packages into the Mods overlay, including definition totals, non-zero categories, prompts, and patches without persisting package metadata or exposing package contents.
- [`344daca`](https://github.com/mmstudio-games/loreloom/commit/344daca0179106d7e50944008a458000d2e55c78): Define non-persistent per-Mod content summaries for the Mods overlay, counting owned top-level definitions by player-relevant category plus declared narrator/NPC prompts and patches.
- [`738b6af`](https://github.com/mmstudio-games/loreloom/commit/738b6af86aa9e9096105bbb44a4957f50b0200aa): Add bounded built-in and directory Mod package loading with canonical hashes, deterministic dependencies and patches, exact ModLock checks, and CLI Mod sources.
- [`feea84b`](https://github.com/mmstudio-games/loreloom/commit/feea84b2ebadc1f286cdbc44dd398db9b247d305): Freeze and implement deterministic Fixed and WorldTime values, typed domain record v1 codecs, structured knowledge and transcript records, Content Document v1 validation, immutable definition registries, and unified preset or generated CharacterSpawnSpec compilation.
- [`f844dd4`](https://github.com/mmstudio-games/loreloom/commit/f844dd442d36222b09bd5475bb8fb8c02a183809): Add fixed, preset, and typed UGC player bootstraps. Content authors can declare deterministic player forms whose validated fields compile into the existing character and parameter records, including durable player-created provenance.
- [`ccf768f`](https://github.com/mmstudio-games/loreloom/commit/ccf768f4a7e21bb445a669f9e6d39c660dbf5842): Load the single playable world from root-level manifest, content, and prompt files; persist its exact WorldLock separately from enabled extension Mods; inject world-owned narration and language policy into Narrator and NPC turns; and remove production demo content and mock bridges. Keep all pre-release save and domain payload structures on their initial v1, rejecting obsolete development saves instead of adding compatibility migrations.
- [`b0dfd1a`](https://github.com/mmstudio-games/loreloom/commit/b0dfd1a59409079f2dd696859d1a8550dc7ef583): Compile initial scenes into deterministic spawn plans and create validated Revision 0 worlds through the shared character factory.
- [`c71e7d4`](https://github.com/mmstudio-games/loreloom/commit/c71e7d451c4c996637b2291a6a9b40beea7ad94a): Simplify narrator NPC orchestration to `create_npc` and `request_npc_turn`, while keeping materialization, generation, replanning, and NPC execution inside the runtime. Move the default generation policy into locked world content, derive scene and agent bindings from authoritative state, advertise only currently schedulable actor IDs, and surface sanitized tool rejection codes in the TUI.
- [`744aa84`](https://github.com/mmstudio-games/loreloom/commit/744aa8464effdf48c892aaf3c7d5545ee9abcf5a): Define the default world launcher, compatible save catalog, and deterministic fixed, preset, or UGC player-creation flow with declarative typed fields and bounded initialization effects.

### Dependencies

- Update loreloom-core to 0.1.0-alpha.0.
